# Student lost and found system

## Project Overview
The College Lost and Found Management System is a C++ console-based application developed to manage lost and found items within a college campus. It provides a simple way to report, view, search, modify, update and delete item records.

## Features
- Report lost or found items
- View all reported items
- Search items by name
- Modify item details
- Update item status
- Delete item records
- Store records permanently using file handling

## Technologies Used
- **Programming Language:** C++
- **Concepts:** Object-Oriented Programming (OOP)
- **File Handling:** C++ file streams (`ifstream` and `ofstream`)
- **Compiler:** GCC / MinGW

## OOP Concepts Used
- Classes and Objects
- Encapsulation
- Abstraction
- Constructors
- Constructor Overloading

## How to Run the Project

1. Download or clone this repository.
2. Open the project folder in VS Code or any C++ IDE.
3. Compile `main.cpp` using a C++ compiler.
4. Run the generated executable.
5. Follow the menu displayed on the console.

### Compile using GCC
```bash
g++ main.cpp -o main
```

### Run
```bash
./main
```

On Windows:
```bash
main.exe
```

## File Storage
The application uses `items.txt` to store item records. Previously saved records are loaded automatically when the program starts.
